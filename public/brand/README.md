# Brand assets

Canonical files for light/dark UI (transparent PNG backgrounds, cropped to artwork):

| File | Use |
|------|-----|
| `logo-lockup-light.png` | Icon + wordmark on light backgrounds |
| `logo-lockup-dark.png` | Icon + wordmark on dark backgrounds |
| `mark-light.png` | Icon only (light) |
| `mark-dark.png` | Icon only (dark) — small UI |
| `mark-dark-hero.png` | Upscaled mark for large hero display |
| `wordmark-light.png` | Wordmark only (light) |
| `wordmark-dark.png` | Wordmark only (dark) |
| `favicon.png` | Favicon — mark on white (opaque), as requested |

`source/` holds the original Photoroom/export filenames (opaque studio backgrounds).

PRD design tokens (Section 5) remain source of truth for colors/typography; these PNGs are the official marks.
