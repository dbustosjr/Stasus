# PRODUCT.md

**Stasus** helps people with vestibular symptoms reduce those symptoms and reclaim steadier days — diagnosed or not — as a general wellness product (no diagnose/treat/cure claims).

## Audience

Adults 18–65 with vestibular symptoms (PPPD, BPPV, vestibular migraine, undiagnosed dizziness, post-acute lingering symptoms).

## v1 product pillars

1. Condition-mapped vestibular rehab exercise library (+ optional webcam practice)
2. Symptom & trigger tracker
3. Hypervigilance / anxiety reduction tools
4. AI notes — daily (after each log), weekly, monthly — Anthropic direct; red-flag escalation
5. Web/PWA on InsForge Sites, **dark-only**, motion-safe UI
6. Usage metrics — personal + admin DAU/WAU/MAU from meaningful actions (local timezone)

## Non-goals (v1)

EEG/BCI, native apps, clinic multi-practitioner workspace, FDA clinical-use version.
